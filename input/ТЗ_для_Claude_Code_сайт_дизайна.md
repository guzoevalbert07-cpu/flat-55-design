## 4. Структура сайта

Одна страница, переключатель опций сверху (sticky), URL-хэш `#eco` / `#std` / `#prem`, чтобы ссылка открывала нужную опцию.

1. **Hero** — название, площадь, три кнопки-опции с ценой.
2. **Концепция опции** — 2–3 предложения + палитра (5 свотчей с HEX) + материалы (4 образца).
3. **План с расстановкой** — SVG в цветах опции (есть в HTML, функция `plan()`); подписать площади и размеры мебели; пунктиром снесённую стену.
4. **Развёртки комнат** — кухня, зона зала, спальня, детская, душевая (функции `kitchen/living/bedroom/kids/bath` в HTML). Улучшить детализацию, но сохранить пропорции по размерам из §2.
5. **Фотореференсы** — 3–4 фото на опцию. Использовать **бесплатные стоковые** (Unsplash API / Pexels API, ключ через `.env`), запросы: «scandinavian white kitchen oak floor», «warm minimalist greige living room», «japandi walnut brass interior» и т. п. Атрибуцию — в футер. **Никаких скриншотов чужих проектов.**
6. **Бюджет опции** — 3 карточки (ремонт / заезд / итого) + таблица по разделам из `3_Саммари` и итогов `1_Ремонт`, `2_Заезд`.
7. **Что купить** — таблица из листа `Закупка_ссылки` + столбец M листа `2_Заезд`: позиция → модель → магазин → ссылка (Лемана ПРО Саратов, Hoff, DNS, «Мария», Сантехника.ру Саратов).
8. **Порядок работ** — 6 шагов из docx (обои → электрика под потолок → пол → потолки → двери → сантехника/розетки → мебель).
9. **Футер** — дата, источники цен, атрибуция фото.

Опционально, если успеваешь: генерация фотореалистичных рендеров через API (Yandex ART / Kandinsky / Stability) по промптам: для каждой комнаты и опции промпт формируется из токенов §3 + размеров §2 («interior render, kitchen 11.8 m2, L-shaped cabinets 2.9+2.4 m, cashmere matte fronts to ceiling, graphite lower cabinets, oak floor, black hardware, track lighting, photorealistic, 35mm»). Ключ — только из `.env`, без ключа секция скрывается.

## 5. Технические требования

- **Стек:** Vite + React + TypeScript (или Astro). Tailwind допустим. Один деплой — статика.
- **Данные:** `scripts/xlsx-to-json.ts` читает `input/Смета_*.xlsx` → `src/data/estimate.json` (листы `3_Саммари`, `1_Ремонт`, `2_Заезд`, `Закупка_ссылки`). Сайт читает JSON, не хардкод.
- **Мобильный экран — приоритет** (владелец и получатели смотрят с iPhone). Проверить на 390 px.
- Шрифт — один семейство (Manrope или Inter, self-hosted или Google Fonts). Без слайдеров с автопрокруткой и анимаций «на скролле».
- OG-теги + `og:image` (борд Стандарта), чтобы превью в WhatsApp/Telegram показывало картинку и заголовок.
- Lighthouse mobile ≥ 90 по Performance и Accessibility.
- Все ссылки на магазины — `target="_blank" rel="noopener"`.

- Не менять планировку и размеры из §2 — они согласованы с планом БТИ и правками брата.

- Не использовать чужие фото проектов и изображения с брендами/персонажами.
