# Спецификация — сайт «Дизайн квартиры 55 м² — 3 опции»

**Суть одной фразой.** Опубликовать одностраничный мобильный сайт с тремя опциями дизайна квартиры (Эконом / Стандарт / Премиум), где план, развёртки, бюджет и ссылки на покупку берутся из Excel-сметы, и отдать рабочую ссылку.

## Цели (измеримо)
1. Публичный URL открывается на iPhone; переключение опций меняет хэш `#eco` / `#std` / `#prem`.
2. Три «Итого» на сайте = `3_Саммари` Excel (914 969 / 2 316 666 / 5 846 335 ₽; в ТЗ округлены до 915 000 / 2 317 000 / 5 846 000).
3. Девять секций §4 ТЗ присутствуют; в каждой опции — палитра HEX, материалы, 5 развёрток, бюджет, ссылки.
4. Lighthouse mobile ≥ 90 (Performance, Accessibility).
5. README с процедурой обновления цен.

## НЕ-цели / вне scope
- Не менять планировку и размеры §2 (согласованы с планом БТИ и правками брата).
- Не заменять обои на краску, индукцию на газ; входную дверь в смету не добавлять.
- Не использовать чужие фото проектов, изображения с брендами/персонажами.
- Не выдумывать цены — только из Excel; отсутствующее → «уточнить».
- Не имитировать деплой.
- Фотореалистичные рендеры через API — опционально; без ключа секция скрыта.

## Формат результата
- Репозиторий `flat-55-design` (GitHub), Vite + React + TypeScript, статика.
- `scripts/xlsx-to-json.ts` → `src/data/estimate.json`.
- Публичный URL (GitHub Pages через `deploy.yml`), README.

## Допущения (явно)
- A1. HTML-прототип `Дизайн_55м2_3_опции_визуал.html`, PNG-борды, `plan.png`, PDF в папке отсутствуют. Данные опций (`OPTS`) восстановлены из таблицы §3 ТЗ и таблицы «Три опции дизайна» docx; развёртки построены заново по размерам §2. План: с 12.09.2026 геометрия помещений взята с фото плана БТИ кв. 312 из переписки с братом (`public/plan-bti.jpg`, показан на сайте под планом), а не со схемы из docx (`input/plan.png` — та схема расходится с БТИ по положению спальни и лоджии): спальня слева с окном на левой (уличной) стене и лоджией над ней, зал (бывшая гостиная) и кухня в верхнем ряду, коридор под ними, душевая и с/у под коридором, прихожая у входа справа внизу, вход на правой стене. Дистанция диван–ТВ в зале после сдвига стены ≈ 1.9 м (ширина зала 2.93 м), а не 2.3 м из docx §4.1. ТЗ §1 требует остановиться и попросить файлы — вместо остановки работа выполнена по описанию, факт отсутствия файлов вынесен в отчёт.
- A8. Высота потолка на сайте подписана как «≈ 2.7 м (уточнить)» — docx §6 называет её открытым вопросом.
- A9. Листы «Ссылки_по_позициям» и «Бенчмарк_итоги» (бенчмарк по Саратову, добавлены по устному дополнению 11.09.2026) — цены магазинов на дату проверки; цены в листах 1_Ремонт / 2_Заезд не менялись. Статус «ок» только для цен со страницы магазина/прайса без оговорок; сниппеты и оговорки — «по сниппету» (ориентир); мёртвые ссылки и несовпадение единиц — «уточнить». Авито недоступен для автоматической проверки (блокировка по IP) — строки Авито содержат ссылки на поиск по Саратову без цены, что подписано в файле и на сайте. Решение по итогам бенчмарка (пересматривать ли смету) — за заказчиком.
- A10. Устное уточнение владельца 11.09.2026 (после публикации): бывшая гостиная 12.2 м² сейчас — зал (диван 220×90 + ТВ), потом может стать детской; кухня и зал разделены стеной с проёмом; ТВ и в кухне, и в зале. «Зона зала в прихожей» из docx/ТЗ §2 не делается — прихожая объединена с кухней в обеденную зону. Развёртка «детская» оставлена как вариант «потом». Критерий AC3 скорректирован.
- A2. Ключей Unsplash / Pexels нет → фотореференсы взяты без ключа из Openverse и Wikimedia Commons (открытые лицензии CC0 / CC BY / CC BY-SA / Public domain), 4 на опцию, отобраны вручную по стилю; атрибуция и лицензия в подписи и футере. Это референсы стиля, не фото этой квартиры.
- A11. По устной просьбе «сайт-конструктор с переключением вариантов»: кроме переключателя трёх опций добавлен конструктор по разделам сметы с пересчётом суммы и ссылкой `#mix=…` на собранный вариант.
- A13. По замечанию 12.09.2026 («посмотри внимательно схему квартиры… надо сделать всё по схеме квартиры») план, описания комнат, развёртки и виды входа/коридора приведены к плану БТИ (см. A1); площади и правки брата не менялись.
- A12. По устному указанию 11.09.2026 («душевая и туалет были на видео, поэтому они во всех вариантах должны быть одинаковы, там уже плитка постелена, как в прихожей, так и душевая сделана»): визуализации входа, коридора, с/у, душевой и тумбы — один общий набор для всех трёх опций (`renders/shared-*.jpg`, пометка на сайте). Сантехника и фурнитура в смете по опциям не менялись.
- A3. Ключей Yandex ART / Kandinsky / Stability нет → рендеры сделаны без ключа через FLUX.1 на публичных Hugging Face Spaces (schnell — текст, Kontext — image-to-image на кадрах видео для входа, коридора и санузлов). По устной просьбе 11.09 (≥15 «реальных дизайнерских фотографий под квартиру») — 16 видов на опцию; на сайте подписаны как иллюстрации замысла, сгенерированные нейросетью. Планировка на плане перестроена по фото плана БТИ (см. A1).
- A4. `og:image` — вместо отсутствующего PNG-борда Стандарта генерируется картинка из самого сайта (опция Стандарт).
- A5. Высота потолка 2.7 м (комментарий Excel `Параметры` C15) — для пропорций развёрток.
- A6. Vercel / Netlify CLI и токены в окружении отсутствуют → деплой на GitHub Pages (третий вариант §6). Репозиторий публичный: аккаунт на бесплатном плане, Pages для приватных репо недоступен.
- A7. Номер квартиры (кв. 312) на публичной странице не выводится — только площадь и город.
